Такском против УМЦ

Фискальный накопитель знает правду: чек либо пробит, либо нет. Приложение сравнивает чеки Такскома с тем, что администраторы завели в УМЦ, и выдаёт список мест, куда идти смотреть руками.

обязательно

Отчёт Такскома

«Такском-Касса» → Фискальные документы, выгрузка в xlsx

Реестр оплат

«Детально по документам (Оплаты)» из УМЦ. Добавьте в отчёт поле «Эквайринговый терминал» — без него безнал не разложить по кассам

Реестр услуг

Оказанные услуги с колонками «Сумма», «Касса» и «Чек пробит»

Ячейки можно перепутать — приложение узнаёт файл по содержимому. Обязателен только отчёт Такскома; каждый следующий файл добавляет проверки. Выгрузки можно брать за месяц: период считается по ним самим.

Эталон — фискальный накопитель. Расхождение в деньгах ищется по дням и кассам; чек, у которого в УМЦ нет пары, показывается отдельно — по нему и идут в программу. Проверено на 11–31.08.2026 и 01–14.09.2026.
